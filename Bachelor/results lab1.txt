Задание 1: Вычислить значение выражения
((a + b)³ - (a³ + 3a²b)) / (3ab² + b³)
при a = 1000, b = 0.0001
Задание 2: Вычислить значения выражений:
1. n---m
2. m--<n
3. n++>m

=== Task 1 ===
Enter value for a: 1000
Enter value for b: 0.0001

Результат для float  : 2207033.0000000
Результат для double : 0.9973844

=== Task 2 ===
Enter integer n: 5
Enter integer m: 10

1) n---m   = -5
2) m--<-n  = false
3) n++>m   = false

       (Объяснение полученных результатов)
Задание 1
• Математически данное выражение тождественно равно 1,
так как (a + b)³= a³ + 3a²b + 3ab² + b³, и после
сокращения в числителе остаётся 3ab² +b³ , что равно
знаменателю.
• Для типа double (результат ≈ 0.9973844): Тип double
имеет высокую точность (15–17 значащих цифр), поэтому
он корректно вычисляет сумму (1000 + 0.0001) без потери
младших разрядов, и результат максимально близок к
истинному значению 1.
• Для типа float (результат 2207033.000000): Тип float
имеет ограниченную точность (всего 6–7 значащих цифр).
При сложении очень большого числа ($a = 1000$) и очень
маленького ($b = 0.0001$) происходит потеря точности
(округление), из-за чего в числителе возникает огромная
погрешность, приводящая к неверному результату.

• Задание 2 (при n = 5, m = 10):
•
1. n---m = -5: Компилятор разбирает выражение как (n--)
- m. Используется текущее значение n (5), вычитается m
(10), получается 5 - 10 = -5 (после чего n уменьшается
на 1).
